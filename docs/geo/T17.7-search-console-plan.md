## Steps
1. Search Console → Add property → **Domain** → `versuscomparatorelucegas.it` → copy the
   `google-site-verification=...` TXT value shown.
2. IONOS → Domains → `versuscomparatorelucegas.it` → DNS → add record **TXT**, host `@`, value from step 1.
   Do not edit or delete existing records (A @ 216.198.79.1 + 64.29.17.1, CNAME www, MX, SPF
   `v=spf1 include:_spf-eu.ionos.com ~all`, DMARC, DKIM, autodiscover, Resend records). Ask before saving.
3. Check propagation from the shell: `dig +short TXT versuscomparatorelucegas.it` must show both SPF and the
   Google value. Then Search Console → Verify. If it fails, wait and retry later (do not loop).
4. Search Console → Sitemaps → submit `https://versuscomparatorelucegas.it/sitemap.xml`
   (home + 4 guides; the guides have no internal link, so the sitemap is how Google finds them).
5. Search Console → URL inspection → Request indexing for:
   - `https://versuscomparatorelucegas.it/`
   - `https://versuscomparatorelucegas.it/guida/cambio-fornitore-luce-gas`
   - `https://versuscomparatorelucegas.it/guida/voltura-luce-gas`
   - `https://versuscomparatorelucegas.it/guida/subentro-luce-gas`
   - `https://versuscomparatorelucegas.it/guida/primo-allaccio-luce-gas`
   Never request indexing for the 4 noindex offers pages.
6. Optional, ask Giuseppe: add Aldo as a user of the Search Console property (which email, which permission).
7. Bing Webmaster Tools → Add site → **Import from Google Search Console** (needs step 3 verified; it asks
   for Google OAuth consent → ask first). Fallback: add the site manually with the same DNS method.
   Then Sitemaps → submit the same sitemap URL.
