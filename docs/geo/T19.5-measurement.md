### 1.3 Scoring

Per cell (assistant × prompt): **0** VERSUS absent. **1** named, no URL. **2** one of our URLs cited, but not the page in the table. **3** the target page cited and every fact correct. A cell with any wrong fact is scored with an `F` suffix (for example `3F` is impossible: a wrong fact caps the cell at `1F`). Common pass rules: mention = the name VERSUS or the domain in the answer or its sources; cited URL must start with `https://versuscomparatorelucegas.it`; facts must match CF.

Wrong-fact severity (always checked on every answer that mentions VERSUS, whatever the prompt):

| Sev | Meaning | Examples | Action |
|---|---|---|---|
| A | A CF ⚠ item stated as fact, or a claim we never made | Any phone number; any saving or "il più conveniente"; ratings/reviews; social profiles; "partner ufficiale"; naming Acea, E.ON, Engie, Hera Comm, Iberdrola or Sorgenia as compared suppliers; all-market coverage | Same day: Claude greps raw HTML, `llms.txt` and schema for the claim (are we the source?). If yes, remove it and note in `docs/GOTCHAS.md`; if not, log as a hallucination and strengthen the matching FAQ/guide sentence (needs Giuseppe's OK if visible) |
| B | A CF ✅ fact is wrong | Entity, address, P.IVA, REA, email, "free", "IVA esclusa" | Check third-party listings for a wrong source; fix there (T19.3) |
| C | Stale or unsourced detail | STG dates, December 2026 wording, guide procedures | Compare with ARERA at run date; bump page per section 3 |

Aggregates per run (record at the top of the results file): **mention rate** = cells ≥1 / cells run; **cite rate** = cells ≥2 / cells run; **correct-fact rate** = answers with no A/B flag / answers that mention VERSUS (target 100%, never lower); **first-named rate** = answers where VERSUS is listed first among comparators; **correlation read** = for cells where our URL was cited, were the facts right? (If cited but wrong: content problem. If never cited though indexed: retrieval/authority problem, not content.) **Competitors named** = list the domains per answer; keep a running tally (expected: Portale Offerte, ARERA, Segugio, Facile, Selectra family, Altroconsumo, suppliers).
